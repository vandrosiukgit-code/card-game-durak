# tools/

Разовые инструменты разработки. **Не часть приложения** — не импортируются
из `app/`, не участвуют в рантайме, не покрываются тестами.

## Содержимое

- `deck_design_system.py` — генератор SVG-дизайн-системы для карт
  (использовался для подготовки ассетов в Langflow). Запускается вручную.

## Правила

- Код в `tools/` может не следовать конвенциям `app/` (см. `CONVENTIONS.md` §3),
  если это разовый скрипт.
- Если инструмент становится регулярно используемым — переносим в `scripts/`
  и приводим к общим конвенциям.
